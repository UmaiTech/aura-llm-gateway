# Redesign v3 — before/after screenshots

Captured with Playwright (Chromium) against production builds of the three
apps, with mocked API responses (synthetic data shaped like the real
endpoints; nothing here is a real workspace). Each image shows the view
before the change (dark, 1440 px) next to it after, plus the light theme
and both themes at phone width (390 px). Reduced motion was on.

Files are prefixed with the commit slice: A (brand, tokens, landing), B
(routing inspector), C (docs, roadmap), D (pricing), Admin.
