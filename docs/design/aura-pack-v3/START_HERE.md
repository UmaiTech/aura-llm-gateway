# Aura coding-agent pack v3

Start with **handoff/LANDING_PRODUCT_SHOWCASE.md** for the new landing page, then give **handoff/AGENT_BRIEF.md** to your coding agent.

This supersedes v2 and includes all six prototype views, brand assets, design tokens, API/file mappings, docs/roadmap/pricing recommendations and acceptance checks.

New in v3: hero product switcher, dedicated Admin and Playground sections, inline preview tabs, direct product CTAs and a sample journey from landing to chat to console.

Run: `cd prototype && python3 -m http.server 8080 --directory dist`.
Open http://localhost:8080/.

Hosted prototype: https://aura-design-prototype.niceraven33.chatgpt.site

No original Aura production files were changed. This is a visual/interaction implementation reference, not a drop-in patch. Prototype responses, routing scores, prices, charts and metrics are simulated.
